# BlazeRidge – Skills-Branch

Nicht Teil der Website (GitHub Pages veröffentlicht nur `main`). Hier liegen die Claude-Code-Skills und Agenten.

| Skill | Zweck |
|---|---|
| webdesign-core | Generator `brief.json → Website`, 10 Scroll-Effekte (GSAP/ScrollTrigger, Lenis, three.js), QA mit Screenshots/Video |
| webdesign-bold-pop | Gelb/Schwarz-Studio-Stil (Blob, Sticker, Reach-out-Footer) |
| webdesign-glass-product | Glas-/Produkt-/App-Stil mit 3D-Produkt und Handy-Mockup |
| webdesign-scroll-showcase | Editorial-Seite mit allen 10 Scroll-Effekten |

Agenten (`agents/`): web-qa (haiku), video-check (haiku), brief-writer (sonnet), make-waechter/anfragen/auftrags/content (haiku).

Wiederherstellen: läuft automatisch über das Setup-Skript der Umgebung „Yputoube“; manuell: `bash <(git show origin/skills:restore.sh)` (Skills, Agenten, Graphify, ~/claude-motion, Piper-Stimme).
Alles kostenlos: GSAP Standard-Lizenz, Lenis MIT, three.js MIT, Graphify Apache-2.0, Google Fonts OFL.

# BlazeRidge – Website

Statische One-Page-Website für TikTok [@blazeridge](https://www.tiktok.com/@blazeridge).

- Scroll-Intro: Laptop klappt auf, Kamera fährt in den Bildschirm (Higgsfield-Film, 96 Einzelbilder in `media/laptop/`).
- Scroll-Tauchgang in den Marianengraben (`media/dive/`).
- Keine Build-Schritte: `index.html` direkt im Browser öffnen oder über GitHub Pages ausliefern.
